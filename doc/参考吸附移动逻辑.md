# ThousandPlayer 多窗口吸附与联动移动系统技术文档

## 系统概述

ThousandPlayer实现了一套完整的多窗口吸附系统，支持三个窗口（主窗口、播放列表窗口、歌词窗口）之间的智能吸附和联动移动。系统基于几何距离检测、状态矩阵管理和图遍历算法，提供流畅的用户体验。

## 吸附检测算法

### checkSnapType 函数
该函数是吸附检测的核心，通过计算两个窗口几何体的边缘距离来判断吸附类型：

```cpp
TP_MainClass::SnapType
TP_MainClass::checkSnapType( const QRect &I_geometry1, const QRect &I_geometry2 ) const
{
    // 水平相交时检测垂直吸附
    if( I_geometry1.right() >= I_geometry2.left()
            && I_geometry1.left() <= I_geometry2.right() )
    {
        if( std::abs( I_geometry1.top() - I_geometry2.bottom() ) <= TP::snapRange )
            return SnapType::ToBottom;
        if( std::abs( I_geometry1.bottom() - I_geometry2.top() ) <= TP::snapRange )
            return SnapType::ToTop;
    }

    // 垂直相交时检测水平吸附
    if( I_geometry1.bottom() >= I_geometry2.top()
            && I_geometry1.top() <= I_geometry2.bottom() )
    {
        if( std::abs( I_geometry1.right() - I_geometry2.left() ) <= TP::snapRange )
            return SnapType::ToLeft;
        if( std::abs( I_geometry1.left() - I_geometry2.right() ) <= TP::snapRange )
            return SnapType::ToRight;
    }

    return SnapType::NonSnap;
}

### 多窗口吸附优先级
系统按以下顺序处理吸附：
1. 吸附到主窗口
2. 吸附到播放列表窗口
3. 吸附到歌词窗口

每个窗口只能在一个方向上吸附一次，避免冲突。

## 联动移动机制

### breadthFirstSearch 函数
使用BFS算法查找与主窗口连通的所有吸附窗口：

```cpp
bool TP_MainClass::breadthFirstSearch( int I_idx ) const
{
    int idx_Current {};
    bool isVisited [ TP::numberOfWindows ] {};
    std::queue < int > queue {};

    isVisited [ TP::mainWindow ] = true;
    queue.push( TP::mainWindow );

    while( ! queue.empty() )
    {
        idx_Current = queue.front();
        queue.pop();

        for( int i { 1 }; i < TP::numberOfWindows; i++ )
            if( ! isVisited[ i ] && snapStatus[ idx_Current ][ i ] )
            {
                if( i == I_idx )
                    return true;
                else
                {
                    isVisited[ i ] = true;
                    queue.push( i );
                }
             }
    }

    return false;
}

## 算法复杂度分析

- **吸附检测**：O(1) - 只涉及简单的几何计算
- **状态刷新**：O(n²) - 需要检查所有窗口对（n=3，实际为常数时间）
- **BFS遍历**：O(n) - 图遍历，n为窗口数量
- **移动处理**：O(n) - 需要检查与所有可见窗口的吸附关系

## 关键设计决策

1. **固定吸附距离**：使用8像素的固定阈值，简化计算
2. **双向吸附状态**：矩阵对称存储，便于双向查询
3. **主窗口为中心**：BFS始终从主窗口开始，确保联动移动的一致性
4. **两步吸附**：先边缘吸附，再边缘对齐，提供更精确的用户体验
5. **状态持久化**：吸附状态随窗口位置一起保存，保持用户体验的连续性

## Notes

- 系统仅支持三个窗口的吸附，扩展性有限但满足当前需求
- 吸附检测基于矩形几何体，不考虑窗口形状的复杂性
- 联动移动仅支持主窗口作为驱动，其他窗口移动不会带动主窗口
- 边界调整（resize）也有类似的吸附逻辑，但实现略有不同
